# telcochurn_project

## Overview
A production-grade machine learning system for predicting customer churn in telecommunications using the IBM Telco dataset. Built with Streamlit, scikit-learn, XGBoost, LightGBM, and SHAP for explainability.

## Essential Commands
* **Build:** `pip install -r requirements.txt`
* **Test:** `pytest -v` (note: no test suite currently exists)
* **Run App:** `streamlit run src/app/app.py` or `python run_app.py`
* **Run Pipeline:** `python run_pipeline.py` (trains models + generates SHAP explanations)
* **Deploy:** `docker-compose up --build`

## Code Organization and Structure

telcochurn_project/

## Application Architecture and Control/Data Flow
```
Raw CSV → load_data.py (clean + preprocess) → train.py (SMOTE + 6 models + SHAP) → models/best_model.pkl → app.py (Streamlit UI)
```

## Naming Conventions and Style Patterns
* Snake case for Python files and functions
* CamelCase for class names
* Pydantic-style field validation in main app

## Testing Approach and Patterns
* Uses pytest with TestClient for API testing
* Tests located in `test_api.py` (if present)
* Run with: `pytest -v --tb=short`

## Gotchas and Non-Obvious Patterns
* `data/cleaned.csv` is a modified version of `data/telco.csv` — keep both in sync
* The `.env` file contains database credentials — never commit it
* Model artifacts (`.pkl`) are gitignored and regenerated by `run_pipeline.py`
* SHAP values require the model to be tree-based (TreeExplainer) or fallback to LinearExplainer
